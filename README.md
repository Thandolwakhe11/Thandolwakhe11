## 📂 Projects

### 💬 Qup: WhatsApp Clinic Queue
**Node.js | TypeScript | React | Supabase | Twilio**

A queue system for clinics that runs on WhatsApp. Patients join the queue by chatting, and staff manage it from a live dashboard.

* WhatsApp chatbot in English, isiZulu and Afrikaans: patients join the queue, get a ticket and an estimated time window, and can check or cancel their place.
* Real-time staff dashboard in React (Next, Pause, Cancel, Walk-in) that updates live through Supabase Realtime.
* PostgreSQL schema with Row Level Security so each clinic sees only its own patients, with secret keys kept on the backend only.
* Alert notifier that avoids duplicate messages, plus a browser chat simulator and a printable QR poster.
* Backend deployed on Render and dashboard on Vercel, with GitHub Actions running tests and builds.

🔗 [Live demo](https://qup-two.vercel.app) · [Code](https://github.com/Thandolwakhe11/qup)
